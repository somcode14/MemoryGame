## 🎮 What's Inside?

CookedBrain currently has **3 mini-games** designed to test different parts of your brain.

### 🧩 1. SUDOKU

A classic Sudoku experience with a CookedBrain twist.

- 6×6 Sudoku grid
- Numbers from 1–6
- Keyboard support
- On-screen number pad
- Erase option
- Hint system
- Mistake tracking
- Timer
- Score calculation

Think you're locked in?

**Prove it. 👀**

---

### ➗ 2. MATH MODE

Numbers start looking suspiciously complicated after a few rounds.

Math Mode challenges you to solve and remember numerical problems across **10 rounds**.

Test your:

- Calculation speed
- Focus
- Memory
- Accuracy
- Reaction time

Get the answer right → **+100 points**

Get it wrong → **Penalty 💀**

---

### 🟦 3. MEMORY MATRIX

Look at the pattern.

Remember the pattern.

| Level | Grid | Tiles |

| 🟠 Level 3 | 4×4 | 5 tiles |
